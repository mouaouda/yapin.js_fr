# Getting help

- **Read the docs first.** The [documentation](docs/README.md) covers every feature, and [examples/](examples/) has runnable bots.
- **Questions, ideas and show-and-tell** go in [Discussions](https://github.com/yapin-js/yapin.js/discussions). Use the Q&A category for "how do I..." questions.
- **Bugs** go in [Issues](https://github.com/yapin-js/yapin.js/issues/new/choose). Include your yapin.js and Node versions and the smallest code that shows the problem.
- **Security problems** must be reported privately. See [SECURITY.md](SECURITY.md).

Problems with Yapin’ itself (your account, a server, the app, the bot hosting service) aren't something this project can fix. Contact Yapin’ for those.

This project is maintained by volunteers, so please be patient. Never post your bot token anywhere; if you do by accident, reset it straight away in **Settings → Developer**.
